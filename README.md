源码获取：ym7k.com/19914/

## 一、软件基础信息

- 运行平台：Windows10 / Windows11（64 位）
- 交付：客户端安装包 + 使用教程 + 提示词模板包
- 数据存储：全部文稿、人物设定、资料以 Markdown/JSON 保存在本地文件夹，可随意备份、复制、迁移
- 模型接入：兼容 OpenAI 兼容接口、DeepSeek、通义千问、GLM、Ollama 本地模型等，自己填 API 密钥即可使用

## 二、核心主打功能

### ✅ 大纲连续创作（核心亮点）

支持分卷、分章大纲树状管理，大纲和正文双向联动；AI 读取全书大纲、前文伏笔、人物设定续写，不会出现前后人设、剧情矛盾，适合长期连载，保持剧情连贯性。可以批量生成单章、多章节正文，按照大纲节奏推进剧情。

### ✅ 整书改写 / 批量润色

支持导入整本稿件，批量改写、统一文风、降 AI 感、调整叙事节奏；支持局部重写、段落扩写、精简压缩、视角转换；改写时自动读取全书设定库，保证改写后人物、世界观统一，不会崩坏设定。

### ✅ 专属资料库（设定库）

独立的小说世界观资料库，录入人物档案、人物关系、势力、地名、功法、道具、时间线、伏笔记录；AI 每次生成自动读取资料库内容，规避人设 OOC、设定冲突，自带人物关系图谱、故事时间轴视图。

### ✅ 写作辅助功能

1. 版本快照：每一次 AI 生成保留草稿对比，支持一键切换版本，AI 生成内容不会直接覆盖原文
2. 字数统计：分卷、分章统计，连载进度一目了然
3. 风格模板：内置网文各类题材提示词模板（玄幻、都市、言情、悬疑、历史等）
4. 导出功能：一键导出整本 TXT、Markdown 稿件，直接给平台投稿
5. 冲突自检：一键扫描全文，检查人设、剧情前后矛盾点

## 三、业务流程

搭建项目 → 录入世界观 / 人物资料库 → 搭建分卷大纲 → 根据大纲生成章节正文 → 润色改写、调整文笔 → 导出定稿文稿

✅ 网络小说作者、网文工作室批量写稿
✅ 长篇故事、剧本、连载文创作者
✅ 不想把稿子放云端、重视稿件隐私的作者
✅ 同时开多本书、需要管理多套世界观设定的写手
